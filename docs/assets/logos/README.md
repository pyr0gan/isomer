# Brand logos

Official logos used in the project README (nominative “powered by” / supported
technology use). **Do not modify or visually combine these files.**

| File | Source |
|---|---|
| `elixir-light.svg`, `elixir-dark.svg` | [Elixir downloads](https://github.com/elixir-lang/elixir-lang.github.com/tree/main/public/downloads/logos) — see [Elixir trademarks](https://elixir-lang.org/trademarks/) |
| `surrealdb-light.svg`, `surrealdb-dark.svg`, `surrealdb-icon.svg` | [SurrealDB brand](https://surrealdb.com/brand) |

Naming here follows upstream: `*-light` is the light-colored mark (for dark
UI); `*-dark` is the dark-colored mark (for light UI).

`elixir-*.svg` had upstream `preserveAspectRatio="none"`; that attribute was
set to `xMidYMid meet` so GitHub does not squash the mark. Paths and colors
are unchanged.

Link back to [elixir-lang.org](https://elixir-lang.org) and
[surrealdb.com](https://surrealdb.com) when displaying these marks.
